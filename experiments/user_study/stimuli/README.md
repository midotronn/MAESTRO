# MAESTRO expert-study stimuli

This directory freezes the six capability-focused 16-second blind-comparison excerpts used by
`maestro-expert-study-v15-llm-gpt4o-k10-front-facing-16s`.

- `selection.json` records the source window, objective diagnostics, and investigator rationale.
- `window-analysis.json` contains the complete sliding-window diagnostic output produced by
  `scripts/rank_interview_windows.py`.
- `comparison-render-report.json` pins the normalized full-song motions and four-GPU Filament
  renders used during selection.
- `live-readiness-report.json` records the final editor, planner, comparison, website-link, and
  affected-test validation.
- `story-reports/` records the selected source sections and authored common-motion events.
- `sources/` contains the six canonical labeled triplets; full commercial recordings and full-song
  composites are intentionally not committed.
- `manifest.json` is generated by `python scripts/build_interview_stimuli.py` and pins source/output
  hashes.
- `player/` is served at `/study/`. Every study session loads the same fixed sequence of six
  phrase-length composites, so playback cannot drift and source method labels never enter the
  participant view. Only the assigned balanced lane order is rendered for each excerpt.
- `player/assignments.json` contains that fixed sequence using numeric lane permutations only.
  The investigator's private decoder remains the authoritative method mapping.

The windows intentionally favor MAESTRO and are suitable for capability demonstration and expert
elicitation. Do not describe their ratings as an unbiased random-sample comparison.

All four approved songs were screened at 16 seconds. Dynamite and Uptown Funk were retained because
they were the only songs with enough non-overlapping windows that jointly preserved high absolute
energy, positive full-window quality and beat margins, and clear MAESTRO separation from both
baselines. The other songs' high-energy long windows were mostly identical to one source baseline
outside brief inserted motions.

Every v15 MAESTRO source uses a required `gpt-4o` storyboard with fallback disabled. LODGE and EDGE
both completed the requested best-of-10 search for every song; the selected seeds and storyboard
evidence are pinned in `story-reports/`.

Generate full-song comparison sources on the study pod, rank them, and rebuild the blind clips with:

```text
pip install opencv-python-headless
python scripts/build_song_comparisons.py /workspace/approved-comparison-runtime.json --resume
python scripts/rank_interview_windows.py /path/to/composites \
  experiments/user_study/stimuli/window-analysis.json --window-seconds 16 \
  --motion-root /path/to/approved-comparisons
python scripts/build_interview_stimuli.py
```
