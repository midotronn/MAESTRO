# MAESTRO expert-study stimuli

This directory freezes the 12 capability-focused blind-comparison excerpts used by
`maestro-expert-study-v11-background-refinement`.

- `selection.json` records the source window, objective diagnostics, and investigator rationale.
- `window-analysis.json` contains the complete sliding-window diagnostic output produced by
  `scripts/rank_interview_windows.py`.
- `manifest.json` is generated by `python scripts/build_interview_stimuli.py` and pins source/output
  hashes.
- `player/` is served at `/study/`. It loads one pre-rendered composite in the participant's assigned
  A/B/C order, so playback cannot drift and source method labels never enter the participant view.
- `player/assignments.json` contains numeric lane permutations only. The investigator assignment
  workbook remains the authoritative method decoder and must not be shown to participants.

The windows intentionally favor MAESTRO and are suitable for capability demonstration and expert
elicitation. Do not describe their ratings as an unbiased random-sample comparison.

Rebuild the evidence and clips with:

```text
pip install opencv-python-headless
python scripts/rank_interview_windows.py docs/static/videos experiments/user_study/stimuli/window-analysis.json
python scripts/build_interview_stimuli.py
```
