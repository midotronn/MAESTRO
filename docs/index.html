MAESTRO
Music-to-motion Agent for Expressive, Structured, Text-guided Reasoning & Orchestration

A training-free, agent-driven system that turns a song into a structured, well-composed dance, then lets you refine any moment of it with plain-English instructions.

Abstract

MAESTRO is a training-free system for composing and editing music-driven dance. It first analyzes musical structure from chroma, MFCC, energy, and downbeats, then an LLM storyboard agent assigns each section a choreographic role, intensity, movement vocabulary, generator preference, and optional recurring motif. A structure-aware selector realizes that plan from complementary LODGE and EDGE motions plus mirrored, retimed, or retrograded motifs, and joins source changes with inertialized transitions. MAESTRO also provides a windowed natural-language editor. Its planner declares measurable goals and routes metric requests to deterministic monotone levers, while requests for genuinely new choreography invoke window regeneration. The executor rejects regressions, adapts regenerated motion to the requested targets on the final crossfaded window, and verifies every goal before saving an undoable checkpoint. This combines whole-song compositional structure with localized, transparent, goal-directed revision.

How it works

Deterministic music analysis exposes the song's form. An LLM storyboard agent composes across that form, and a planner-executor agent revises any selected window with verified tools.

1. Composition: the storyboard agent

STAGE 1

Structure analysis

Chroma, MFCC, energy, and downbeats produce sections, repetition labels, roles, and an energy arc. This stage is deterministic and has a robust musical fallback.

STAGE 2

Storyboard agent

An LLM, with a deterministic fallback, authors each section's role, target intensity, movement vocabulary, generator preference, and any motif recurrence or transformation.

STAGE 3

Structure-aware assembly

Each section scores LODGE, EDGE, and eligible motifs for plan alignment and local coherence. Source changes are joined with training-free inertialized transitions.

2. Editing: a planner-executor loop

Structure-aware choreography

For each song: the 3-way comparison, the detected structure and per-section source, the storyboard, and the metrics.

The live editor

Refine any moment of the dance with natural language.

Select a time window on the beat-aligned timeline and describe the change in your own words: “calmer but keep it tight to the beat”, “explosive hits on the drop”, “flip and reverse this”. A planner and executor agent apply the edit, verify it against every requested goal on the final spliced motion, protect artifact guardrails, and show their reasoning. Then compare the window before and after side by side.
